## What I'm Building

### Groot — AI-Powered Ecommerce Support
[`voltimax-ai-service`](https://github.com/M4MEET/voltimax-ai-service) | [`voltimax-chat`](https://github.com/M4MEET/voltimax-chat)

Built an AI customer support chatbot using LangGraph, FastAPI, and WebSocket streaming, integrated with Shopware 6 and Zendesk. Handles product search, order verification, vehicle compatibility checks, and ticket creation. Designed the LLM query pipeline with intent classification, smart model routing, semantic caching, and RAG retrieval — reducing latency by ~40% and LLM costs by ~30%. Includes AI observability via LangSmith tracing, hallucination detection, and session analytics.
